# Название проекта: "Transaction analysis application"

---
## Основная идея:

Приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, 
а также предоставлять другие сервисы.

## На данном этапе проекта разработано пять основных рабочих модулей:
```
 --  views.py  --  main.py  --  utils.py  --  reports.py  --  services.py  --
```
---
## Краткое описание модуля views.py : 
```
Функция main_page принимает строку с датой и временем и преобразует её в объект datetime.
Вызов функции get_exchange_rate() из utils.py для получения актуального курса валют.
Формирует JSON-ответ и логирует информацию о выполнении.
```
